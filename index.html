Ship Receipts

A local CLI for turning shipped work into portable proof receipts, scored progress, and a static runway you can publish.

View the repo See the game layer 
npm install -g ship-receipts
ship-receipts create \
  --name "public release" \
  --kind release \
  --url https://github.com/you/project \
  --subject "you" \
  --hash
ship-receipts score public-release.receipt.json

Proof, not vibes

Receipt first

Record what shipped, who shipped it, where it lives, and how it can be checked.

Local scoring

Score receipts and streaks locally without sending private work to a hosted service.

Static runway

Export a small static site from receipts or git history when you want a public trail.
